About Goslin

Goslin is a grammar-based parser for lipid names.

Goslin harmonizes every name it can read.

The shorthand nomenclature is developed by the Lipidomics Standards Initiative.

Retention and privacy

Results are kept for 7 days.

With your consent, the web application counts page views with Matomo.

The server counts each validation anonymously.
