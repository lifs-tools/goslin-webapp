About Goslin

Goslin parses lipid names with a set of grammars and reports the level at which a name describes the lipid, from species (PC 34:1) to complete structure. Levels and names follow the updated lipid shorthand nomenclature. We work with the Lipidomics Standards Initiative on the nomenclature used to report lipid identifications.

Found a problem?

If a name is read incorrectly, report it on GitHub or contact us. LIFS is funded by the BMFTR as part of de.NBI.

What changed on this page, and why

  1. A Names that could not be read come first, each with its line number, Goslin's message, and the part where reading stopped underlined. Users fix them in place and press "Re-run corrected names". Only those names are sent again, and the ones that now work join the table, marked "corrected". "Remove" drops a name from the result.
  2. B A filterable table replaces the collapsed card per name: one row per lipid with the main facts. ▸ opens the details that used to fill each card (grammar, LIPID MAPS links, database entries, chain table). Filtering by level or category helps with long lists.
  3. C "Download table (TSV)" is the main action of the page: a filled button next to the title, repeated under the table. The file has the same columns as the table plus every detail column, and includes the names that still fail, with their messages.
  4. D Every name keeps the line number it had in the text box or file (blank lines count, so the numbers match the user's own file). The table is sorted by line by default. Corrected names keep their original line and go back to their place in that order. The TSV starts with the same line column.
  5. Masses and formulas are illustrative here, not taken from a Goslin run.
